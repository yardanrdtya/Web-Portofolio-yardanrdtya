## 🌐 Deskripsi Website
Website portofolio pribadi berbasis HTML dan CSS yang menampilkan profil, keterampilan, pengalaman, dan sertifikat.
Website ini dibuat sebagai tugas Mini Project 1 – Praktikum Pemrograman Berbasis Web.

---

## 🧩 Struktur Website
Website terdiri dari beberapa section utama yaitu:
- Home (Hero)
- About Me
- Skills
- Experience
- Certificates
- Footer
